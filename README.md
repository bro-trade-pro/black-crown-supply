# Black Crown Supply

Site B2B de **Black Crown Supply**, marque de Bro Trade Pro.

## Stack
- Next.js
- Supabase (catalogue, comptes salons, commandes, stockage images)
- Vercel
- Stripe à intégrer pour l'acompte de 50 %

## Variables Vercel
Créer les variables suivantes dans Vercel :
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

Aucune clé secrète ne doit être commitée dans ce dépôt public.
